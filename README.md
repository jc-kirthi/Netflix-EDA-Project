# Netflix Exploratory Data Analysis

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Description
Performed data cleaning and exploratory data analysis on Netflix Movies and TV Shows dataset.
Created 5 visualizations to analyze content trends, ratings, countries, and duration.

## Key Insights
- Movies dominate Netflix catalog
- Content addition peaked after 2016
- USA and India are top producers
